# 0002 · Node 22 como versão mínima

*10/10/2026 · aceita*

## Contexto

Os testes rodam com `node --test --experimental-strip-types`, que exige Node 22.6 ou
superior. O `Dockerfile` já usava `node:22-alpine`, mas o README pedia Node 18.18.

## Decisão

Node 22 em todo lugar: `.nvmrc` com `22`, `engines.node` com `>=22.6` no `package.json`,
CI lendo a versão do `.nvmrc`.

## Consequências

Quem roda com Node 18 ou 20 recebe aviso do npm. Ao migrar para Node 24, basta trocar o
`.nvmrc` e o `Dockerfile`.
